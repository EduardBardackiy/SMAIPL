# Бот поиска новостей RSS для контент-завода

Пример ассистента/бота который показывает пользователю свежие новости про ИИ из RSS лент и по кнопкам сохраняет выбранные материалы в Google Sheets. Проект построен по принципу детерминированного бэкенда: вся логика находится в Google Apps Script, а ассистент (SMAIPL/LLM) работает как “тонкий адаптер” — принимает сообщения и нажатия кнопок, вызывает API скрипта и отображает строго то, что вернул сервер. Нужна подписка на сервис https://rss.app/  и созданные там фиды. В примере в качестве фидов выступают два ТГ канала по тематике ИИ и нейросети.

Что умеет
•	Загружает новости из заданных RSS фидов (rss.app).
•	Формирует очередь новостей на пользователя и показывает карточки “1 из N”.
•	Поддерживает сценарий с кнопками:
•	Найти новости
•	Подтвердить (сохранить в таблицу)
•	Пропустить (следующая новость)
•	Завершить
•	Сохраняет подтверждённые новости в Google Sheets с защитой от дублей.

Архитектура
•	Google Apps Script (gas_script_rss.js) — state machine, источник истины:
•	хранит queue/currentIndex/savedCount в ScriptProperties,
•	отвечает JSON’ом: { success, message, inline_keyboard },
•	пишет данные в Google Sheets.
•	SMAIPL/LLM + prompt (prompt_v10_stateful.txt) — строгое правило:
•	на любое действие пользователя → вызов функции 302 (google_run_app_script) с user_id и command,
•	ассистент не придумывает новости и не изменяет ответ GAS,
•	кнопки формируются из inline_keyboard в формате ##INLINE:[...];[...]##.
Зачем этот пример полезен
•	Показывает, как строить Telegram бота, где LLM не “рулит логикой”, а работает как интерфейс к детерминированному API.
•	Удобная база для доработок: добавление новых источников, фильтров, правил отбора, формата карточек, лимитов, дополнительных команд и аналитики по сохранённым новостям.

Быстрый старт (что нужно настроить)
1.	Задеплоить gas_script_rss.js как Web App в Google Apps Script.
2.	Указать:
•	список RSS фидов в RSS_FEEDS,
•	GOOGLE_SHEET_ID в Script Properties (или в настройках проекта, как у вас принято).
3.	В prompt_v10_stateful.txt вставить URL Web App и подключить промпт в SMAIPL.
4.	В SMAIPL выбрать модель и убедиться, что при нажатии кнопок всегда вызывается google_run_app_script.
Важно
Проект рассчитан на то, что ассистент не генерирует новости и не заменяет ответы сервера. Если платформа/модель иногда нарушает это правило, все ключевые действия всё равно контролируются GAS, а логи позволяют быстро диагностировать проблему на стороне модели/платформы.
